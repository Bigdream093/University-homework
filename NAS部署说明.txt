墨痕 · 绿联 NAS Docker 部署说明（2026.09 统一更新版）
================================

适用设备：Intel N100 等 x86-64（linux/amd64）绿联 NAS。
版本：2026.09 统一更新版（课程归档/复制、分组作业、延期审批、提交回执、
定时通知、问答隐私、下载统计、上传重试、软件内使用手册等十二项功能）。
镜像内不含任何业务数据，首次启动即为全新初始化状态。

一、准备部署目录
在 NAS 共享文件夹中新建 hw-app 目录，并放入以下文件：
- mohen-hw-app-2026.09-linux-amd64.tar
- docker-compose.yml
- .env.example

再在同一目录新建两个空目录：data、uploads。

重要：上线时保持初始化状态——data 和 uploads 目录必须为空，
不要把任何旧的数据库或附件放进这两个目录。首次启动时系统会自动
创建全部数据表，并生成唯一的初始教师账号。

二、导入镜像
在绿联 Docker 应用的“镜像”页面导入 mohen-hw-app-2026.09-linux-amd64.tar。
导入完成后应看到镜像 hw-app:2026.09。
若 NAS 上还保留旧版镜像 hw-app:1.0.0，可暂不删除，待新版验证无误后再清理。

三、设置环境变量
复制 .env.example 并命名为 .env，把 JWT_SECRET 改成足够长、随机且仅自己保存的字符串。
不要在正式环境中使用示例值。

四、创建并启动 Compose 项目
1. 打开绿联 Docker 应用的“项目”或“Compose”。
2. 项目目录选择刚创建的 hw-app 目录。
3. Compose 文件选择 docker-compose.yml。
4. 启动项目。发布版直接使用已导入的 hw-app:2026.09，不需要在 NAS 上构建源码。
5. 时区：compose 已固定 TZ=Asia/Shanghai，所有业务时间（截止、定时通知、回执）以北京时间为准，请勿改动。

五、访问与首次登录
局域网地址：http://NAS的局域网IP:34567
例如：http://192.168.1.100:34567

初始教师账号：teacher
初始密码：123456

登录后请立即修改教师密码，再创建或导入学生账号。首次启动大约需要
数秒完成初始化；若页面暂时打不开，等待容器日志出现“作业管理App已启动”再访问。

六、验证初始化是否成功
1. 浏览器打开 http://NAS的局域网IP:34567/api/health，
   应返回 ok:true、version:"2026.09"、tz_configured:true。
2. 用 teacher/123456 登录，创建一门测试课程，确认数据出现在列表中。
3. 登录后页面右上角“帮助/使用说明”内置了完整的教师/学生操作手册，
   可搜索、可下载 Markdown 副本，无需外部文档网站。
4. 验证通过后删除测试课程即可投入使用。

七、桌面端
Windows 教师和学生分别安装 release 文件夹中的对应 EXE；macOS 学生按芯片
类型选择 AppleSilicon-arm64 或 Intel-x64 ZIP，解压后把“墨痕学生端.app”拖入
“应用程序”。首次启动时填写上面的 NAS 地址。
桌面端只负责连接 NAS 服务；本次更新保持桥接接口兼容，已有桌面端在 NAS
升级后按 F5 刷新即可继续使用，无需重新安装。

八、数据与备份
数据库保存在 data 目录，作业、通知附件和学习资料保存在 uploads 目录。
升级、迁移或回退前必须同时备份这两个目录到项目外。

九、从旧版本升级（可选）
如果将来要把已运行旧版（1.0.0）的 data 目录迁移到本版本：停止旧容器、
备份 data 与 uploads 后，将两个目录原样放入新部署目录再启动，系统会自动
执行兼容迁移，不清空历史数据。本次全新上线不需要执行这一步。

十、外网访问
确认局域网访问正常后，再配置域名和 HTTPS。不要把未加密的 HTTP 服务直接暴露到公网。

十一、回退
若新版运行异常：停止容器，保留现场日志，恢复旧版镜像与备份的 data/uploads
后按本文流程重新启动。回退操作应在副本上先演练一遍。
