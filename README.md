# 墨痕 · 高校作业管理 App

面向单教师、约300名学生的轻量作业管理系统。支持课程与名单管理、Excel原序导入、作业发布、文件/在线提交、文件名自动规范化、截止前24小时提醒、迟交确认与标记、重交替换、教师筛选批改、退回和成绩表导出。

## 本地运行

需要 Node.js 20 或更高版本。

Windows 用户启动服务后，可在浏览器访问登录页。

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。首次运行会自动创建数据库和教师账号：

- 教师：`teacher` / `123456`

生产构建：

```bash
npm run build
npm start
```

生产环境由 Express 同时提供 API 和 `web/dist` 静态页面，访问 `http://localhost:3000`。

## 学生名单模板

Excel 第一行是表头，A列为学号，B列为姓名，从第二行开始读取。新学生默认密码为 `123456`，已有学生账号会直接加入课程。

## Docker / 绿联 NAS

1. 复制 `.env.example` 为 `.env`，把 `JWT_SECRET` 改成长随机字符串。
2. 运行 `docker compose up -d --build`。
3. 访问 `http://NAS地址:34567`。

非技术用户可直接查看项目根目录中的 `绿联NAS部署说明.txt`（发布包在根目录 `发布/` 文件夹）。除了浏览器访问，另提供教师端、学生端 Windows 桌面安装包（Electron 封装，位于 `desktop/release/`），安装后填写 NAS 服务器地址即可使用。

数据库保存在 `data/`，提交文件保存在 `uploads/`。备份这两个目录即可恢复全部业务数据。正式暴露到公网前应配置 HTTPS，并关闭路由器公网管理入口。

## 安全说明

- 学生成绩与教师评语不会由学生接口返回。
- 文件下载同时校验角色、课程归属和提交人身份。
- 上传文件限制为白名单扩展名和单文件200MB。
- 提交时间与超时状态只按服务器时间计算。
- 上传文件对教师显示并下载为“姓名_学号_提交时间_准时或迟交.扩展名”，服务器内部文件名保持唯一。
- 全班提交完成后，教师端可一键下载全部原文件；教师 EXE 会在电脑桌面创建以作业名命名的文件夹，浏览器则逐个下载到默认下载目录。
- 距离截止时间不足24小时显示黄色提醒；截止后仍可提交，但会显示红色提醒并标记为迟交。
- 学生重新上传文件时，新文件替换上一次实体文件；提交历史保留文件名、时间和迟交状态。
- 密码使用 bcrypt 哈希；JWT 默认24小时失效。
