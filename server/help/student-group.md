# 学生：分组作业
版本：2026.09 统一更新版

## 用途
参与老师设置的分组作业：查看本组、按权限提交、共享本组结果。

## 重要规则
- 分组作业整组共用一份当前提交、提交次数、状态和批改，**不是每人各交一次**。
- 默认由组长提交；老师也可以指定一名组员，或允许任一组员提交。无提交权的组员仍能查看本组状态、文件和回执。
- 发布作业时成员快照即固定；之后老师调整课程分组模板不影响本次作业。
- 未被安排进本次作业的学生显示"本次未安排"，不算未交。
- 退回原因全组可见；成绩和教师评语对学生隐藏。

## 操作步骤
1. 打开分组作业，页面显示本组成员、你和谁的提交权、本组提交状态和有效截止时间。
2. 有提交权时按个人作业相同方式上传；提交前若本组已有人交了新版本，系统会要求你刷新确认，避免静默覆盖同伴成果。
3. 提交成功后，全组成员都看到"本组已提交"和实际提交人。
4. 在"历史与回执"中查看本组历史、下载本组保留的文件。

## 常见失败原因
- "你不是本组当前有权提交的成员"：联系老师调整提交人或权限。
- "本次作业未安排你参与"：你不在本次作业的分组快照中，不影响其他作业。
- "本组已有更新，请刷新后确认再提交"：组员刚提交过，刷新页面确认后再操作。
