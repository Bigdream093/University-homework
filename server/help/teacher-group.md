# 教师：课程分组与分组作业
版本：2026.09 统一更新版

## 用途
建立课程分组模板，发布按组提交的作业。

## 建立分组模板
1. 课程详情 → "分组"标签 → "创建小组"。
2. 填写组名，从当前课程学生中勾选"固定成员"，并指定组长。
3. 每名学生在一个课程分组方案中只能属于一组；保存时系统会检查重复。
4. 可随时编辑或删除模板小组；删除模板不影响已发布作业的成员快照。

## 发布分组作业
1. "发布新作业" → "作业组织方式"选"分组作业"，并选择"小组提交权限"：
   - 指定成员提交：每组的提交人默认为组长，可在作业分组设置中更换。
   - 任一组员提交：组内任何成员都可以提交。
2. 先保存草稿，然后在作业卡片上打开"作业分组设置"，从课程分组模板中选择参与本次作业的小组，点击"保存成员快照"。
3. 检查参与范围：未覆盖的学生显示"本次未安排"，不算未交。
4. 点击"发布"。发布后成员快照锁定，之后修改课程分组模板不会改写本次作业的历史。

## 提交、批改与统计
- 整组共用一份当前提交、提交次数和批改结果；提交列表显示组名、成员、实际提交人、时间和迟交状态。
- 作业统计以"已交 X 组 / 应交 Y 组"为主，参与人数单独显示。
- 成绩导出中每位参与学生各占一行并附组名，显示相同的小组成绩；未安排和未交状态分开标记。
- 批量下载按组组织，每组只收录一次，文件名使用小组名和提交时间。

## 常见失败原因
- 发布失败"分组作业必须先配置成员快照"：先完成第 2 步。
- 发布失败"快照成员已退课"：重新编辑快照，剔除已退课学生。
- "小组没有有效提交人"：指定提交模式下，为该组更换当前在课的提交人。
