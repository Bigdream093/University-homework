# 一、作业管理

### 发布作业

1. 进入课程的“作业管理”栏目，点击“发布新作业”。
2. 填写作业标题和要求，设置作业类型、截止时间、满分、学生自行重交次数和提交方式。自行重交次数不含首次提交；教师退回后的更正提交另计。
3. 文件作业可限制文件后缀和大小；需要学生填写文字答案时，可添加必答题目和答题规范。
4. 如需查看作业图片，请勾选图片预览要求，并设置图片数量。学生须按要求另交 JPG 或 PNG 图片。
5. 点击“保存”后，作业处于草稿状态，学生暂时看不到。检查无误后点击“发布”。
6. 分组作业需要先保存草稿，再配置本次作业的参与小组和提交权限，完成后才能发布。

### 查看提交与批改

1. 打开相应作业的提交页面，按“未交”“待批改”“已退回”“已经评分”筛选，也可搜索学号或姓名；“只看迟交”是独立筛选，可与已提交的各批改状态组合使用。
2. 点击缩略图可直接放大查看图片。点击“评分”进入批改界面，查看预览图片、必答题答案和源文件。多张预览图可逐张切换并放大查看。
3. 填写成绩和评语后保存。成绩不能超过作业满分，教师评语仅教师端可见。
4. 需要学生修改时，点击“退回”并填写原因。学生会看到退回原因，并获得一次更正提交机会；重交后，作业再次进入待批改状态。
5. 已评分的作业可通过“查看评分”进入批改界面，再点击“修改评分”。已评分提交会锁定；如需学生重做，请在批改界面选择“退回重做”。
6. 勾选多份待批改作业后，可统一评分或退回。批量操作前请核对选中的记录。

### 截止时间与延期

1. 是否迟交以服务器确认提交的时间为准。迟交标记不改变批改状态，迟交且未评分的作业仍在“待批改”中。截止时间留空时，作业不限时。
2. 在作业页面的“延期申请”区域查看并审批学生申请。拒绝申请时须填写说明。
3. 延期获批后只影响之后的提交，不会修改已有提交的时间和迟交记录，也不会增加允许提交次数。
4. 作业关闭后停止接收提交；需要继续接收时，可重新发布。课程归档后，相应操作进入只读状态。
