# 教师：发布个人作业
版本：2026.09 统一更新版

## 用途
发布文件、图片、视频或在线作答类作业，设置截止时间、重交次数和提交模式。

## 操作步骤
1. 进入课程 → "作业"标签 → "发布新作业"。
2. "作业组织方式"选择"个人作业"（分组作业见分组章节）。
3. 填写作业标题（必填）和作业要求。
4. 设置：
   - **类型**：文档/文件、图片、视频、在线作答。
   - **截止时间**：留空为不限时；到截止时刻相等算准时，之后提交标记迟交但仍会接收。
   - **满分**、**允许重交次数**（-1 为不限）。
   - **提交模式**：覆盖模式（新提交替换旧文件，旧文件删除）/ 追加模式（保留各次文件）。
   - **文件大小上限**：100M / 200M / 500M / 1G（在线作答无此项）。
5. 点击"保存"后作业为草稿；确认无误后点击"发布"对学生可见。
6. 已发布作业可"关闭"（停止新提交，之后可"重新发布"）；已有提交的作业不能再切换个人/分组类型。

## 截止与迟交
- 是否迟交由服务器最终确认提交的时间决定，与学生的上传开始时间无关。
- 学生获准延期后按其个人有效截止时间判定；你调整公共截止时间不影响已生成的提交记录。

## 常见失败原因
- 保存失败提示分值/次数无效：满分须为正数，重交次数为 -1 或非负整数。
- 发布分组作业失败：需先在"作业分组设置"中配置成员快照（见分组章节）。
