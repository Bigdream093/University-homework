# 教师：学习资料与下载统计
版本：2026.09 统一更新版

## 用途
上传和维护学习资料，查看每条资料的下载统计。

## 上传与更新
1. 课程详情 → "资料"标签 → "上传资料"。
2. 填写标题（必填）和说明，选择文件，点击上传。课程资料单文件最多 10GB，页面显示上传进度。
3. "编辑"可更新标题、说明或替换附件；上传请求有防重复保护，网络重试不会生成两条资料。
4. "删除"移除资料及其附件。

## 下载统计
- 资料列表显示每条资料的"学生下载次数"；点击"下载名单"查看学生账号、姓名、累计次数和最近下载时间。
- 统计口径：学生完成完整下载才计 1 次；同一学生重复下载累计；教师下载、失败和取消的下载、视频拖动进度条的分段请求都不计。
- 统计针对资料条目：替换附件或改标题保留累计数字；需要重新统计请新建资料条目。
- 计数自本次更新上线后开始记录，属于使用统计，不是学习成果依据。

## 常见失败原因
- 上传失败可点击重试；系统会先查询上一次请求是否已保存，不会重复添加。
- 超过 10GB 的文件不会保存；可先压缩、拆分后分别上传，并确认 NAS 有足够剩余空间。
- 替换附件后旧文件被删除，已下载的学生不受影响。
- "下载名单"仅任课教师可见，学生看不到账号明细。
