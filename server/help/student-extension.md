# 学生：申请延期
版本：2026.09 统一更新版

## 用途
因个人原因申请延长某次作业的截止时间，并查看审批结果。

## 前提条件
- 作业已发布且设置了截止时间；课程未归档、作业未关闭。
- 同一作业同一人（或小组）同时只能有一条待审批申请。
- 只能申请未来的时间，且必须晚于你当前的有效截止时间。

## 重要规则
- 申请提交不等于批准；未批准前仍按原截止时间判定迟交。
- 批准后，你的有效截止时间取"公共截止时间"和"批准时间"中较晚者，只影响之后的提交，不改变已产生的迟交记录和回执。
- 延期不增加允许提交次数，也不能绕过作业关闭或课程归档。
- 延期理由只有你和任课教师能看到；小组延期中，其他组员可查看状态和截止时间，但看不到申请理由和老师的审批说明。

## 操作步骤
1. 打开作业详情，点击"申请延期"。
2. 填写理由和希望延长到的时间，确认提交后状态为"待处理"。
3. 待处理状态可点击"撤回申请"；批准/拒绝后不能撤回。
4. 老师拒绝时会写明理由，你可以在申请列表中查看。

## 常见失败原因
- "仅有截止时间的已发布作业可以申请延期"：作业未设截止或已关闭。
- "已有待审批申请"：等老师处理或先撤回原申请。
- "申请时间必须晚于当前截止时间和现在"：填一个更晚的未来时间。
- 作业被关闭后老师不能批准，只能拒绝；课程归档会自动取消待处理申请。
