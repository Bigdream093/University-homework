# 教师：审批延期申请
版本：2026.09 统一更新版

## 用途
审批学生的个人延期和小组延期申请。

## 查看申请
- 作业页的"延期申请"面板列出全部申请：申请人（或小组）、理由、希望延至的时间、状态和审批记录；可按待审批筛选。
- 延期理由仅申请人和任课教师可见；小组延期中其他组员只能看到状态和时间。

## 操作步骤
1. 打开待审批申请，点击"审批"。
2. **批准**：可沿用学生申请的时间，也可以调整。批准时间必须晚于当前有效截止时间和现在。批准后该学生（或该组）的有效截止时间取"公共截止"和"批准时间"中较晚者。
3. **拒绝**：必须填写说明，学生会看到拒绝理由。
4. 每条申请只能审批一次，重复点击不会产生第二个结果。

## 规则与边界
- 作业关闭后**不能批准**，但仍然可以拒绝；重新发布作业后可对新的申请审批。
- 课程归档会自动取消全部待审批申请并记录"课程归档"，恢复课程不会恢复这些申请。
- 批准只影响之后的提交：已产生的迟交标记、旧回执和旧文件名不会被追溯修改。
- 延期不增加允许提交次数；小组延期对该组所有成员生效，不影响其他组。
- 教师清空作业的公共截止时间时，系统会自动取消尚未审批的延期申请，并记录取消原因。

## 常见失败原因
- "批准时间必须晚于当前截止时间和现在"：填一个更晚的未来时间，或拒绝该申请。
- "作业已关闭，不能批准延期"：改为拒绝，或重新发布作业。
- 申请不存在：可能已被学生撤回或已审批。
