# 一、查看与提交作业

### 进入课程与查看要求

1. 登录后进入“我的课程”。如果没有相应课程，请输入教师提供的 6 位邀请码加入，再点击课程卡片进入课程。
2. 打开“作业”栏目中的相应作业，仔细阅读作业要求、有效截止时间、允许的文件类型、大小和预览图要求。

### 提交作业

1. 按要求填写必答题、选择源文件；如果要求图片预览，还需上传符合要求的 JPG 或 PNG 图片。
2. 点击“确认提交”后等待系统完成保存，以“提交成功”和回执信息确认结果。上传进度到 100% 不代表保存完成。
3. 个人作业文件提交后自动命名为“姓名_学号_提交时间.扩展名”；分组作业使用“小组名_提交人学号_提交时间.扩展名”。文件名不再添加“准时／迟交”。
4. 是否迟交按服务器确认提交的时间计算，上传开始时间不等于提交时间，请为大文件预留上传和保存时间。

### 重交、退回与延期

1. 尚未评分时，可按照作业设置自行重交；自行重交次数不含首次提交。已经评分的作业锁定修改，如需更正请联系教师退回。
2. 作业被退回后，请先阅读退回原因，再修改并重新提交。退回后的更正提交不占自行重交额度，但会计入总提交次数；更正提交后重新进入待批改。
3. 如需延期，可在作业详情中申请并填写理由和期望时间；教师批准后，新的有效截止时间才会生效。
4. 分组作业由全组共用一份提交记录、提交次数和批改结果，教师设置哪些组员可以提交。

### 上传中断与重试

1. 需要暂停时使用页面提供的暂停按钮，再继续上传；断网或刷新后按提示重新选择相同文件，以查询结果或服务器断点为准。
2. 保存状态不明确时，使用页面提供的查询或重试功能确认结果，不要连续重复提交。
