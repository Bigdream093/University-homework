# 学生：提交作业、上传进度与失败重试
版本：2026.09 统一更新版

## 用途
提交个人作业，查看上传进度，并在网络失败后安全重试而不重复提交。

## 提交前
- 页面顶部显示截止时间和剩余时间；截止时刻相等算准时，超过算迟交。是否迟交以服务器最终确认时间为准，上传开始得早不保证准时。
- 文件作业必须上传文件；在线作答作业填写文字内容。
- 注意提交模式：覆盖模式的新提交会替换上一次文件（旧文件不再保留）；追加模式保留各次文件。替换前系统会弹窗确认。

## 操作步骤
1. 进入课程 → 作业 → 打开作业详情。
2. 选择文件或填写作答内容，点击"确认提交"（超过截止时间时按钮为"仍要迟交"）。
3. 上传中显示"上传中 X%"和已传/总大小；进度到 100% 后进入"正在保存，请勿重复提交"。
4. 只有看到"提交成功"和回执信息才算完成。成功后可在历史与回执中再次查看。

## 失败、取消与重试
- 上传中锁定重复点击；失败后保留已选文件和文字，可直接重试。
- 点击"取消等待并查询"或网络中断后，系统先向服务器查询这次请求的结果：已保存则直接显示原回执，不重复交作业、不消耗提交次数。
- 处理中请稍后再查询；确认失败后用同一文件重试。
- 刷新页面后浏览器无法恢复文件选择，需重新选择同一文件再查询/重试。
- 更换文件或修改答案属于新的提交意图，会生成新的请求编号。
- 身份过期、格式不支持、超过大小限制或无权限时不会自动重试，请按提示处理。

## 常见失败原因
- "该作业限制单文件不超过 X"：更换符合大小的文件。
- "已达到允许提交次数"：重交次数用完；退回和延期不会增加次数。
- "本作业需要上传文件提交"：文件作业必须选择文件。
- 一直显示"正在保存"：点击查询按钮确认服务器结果，不要反复重新提交。
