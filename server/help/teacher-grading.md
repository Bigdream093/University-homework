# 教师：批改、退回、下载与成绩导出
版本：2026.09 统一更新版

## 用途
查看个人/小组提交，评分、退回、批量下载作业文件和导出成绩表。

## 查看提交
1. 课程 → "作业" → 点击某作业的"查看提交"。
2. 列表按学生（或小组）展示：提交状态、提交时间、迟交标记、提交次数；支持按学号姓名搜索和按状态筛选（未交/已交/迟交/已退回/已评分）。
3. 点击单个提交可查看历史版本并下载文件；在线作答可下载为 txt。

## 批改与退回
- "评分"：填写成绩（0 到满分）和评语。评语仅保存在教师端，学生端不显示成绩和评语。
- "退回"：必须填写退回原因（学生可见），提交状态变为已退回，学生可重新提交。
- 学生重新提交会清除上一次的批改结果；退回不消耗提交次数限制以外的次数。
- 分组作业按组批改：成绩和评语保存在该组提交上，组内成员状态同步变化。

## 批量下载
- 作业页使用批量下载入口，打包全部仍保留的提交文件；追加模式包含每个历史版本。
- 分组作业每组只收录一次，文件名含小组名、提交时间和准时/迟交标识。

## 成绩导出
- 点击"导出成绩表"生成 Excel：学号、姓名、提交状态、提交时间、是否超时、成绩、评语。
- 分组作业导出时每位参与学生各占一行并附组名，显示相同的小组成绩；未安排学生标记"未安排"，未交小组对应成员标记"未提交"。
- 导出按发布时的成员快照生成，之后学生退课不影响历史导出的完整性。

## 常见失败原因
- 下载包为空或提示"还没有学生提交作业"：无人提交时不能打包。
- 评分被拒：成绩超出该作业满分。
- 归档课程只能查看和下载，不能评分或退回。
