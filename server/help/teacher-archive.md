# 教师：归档、恢复与复制课程
版本：2026.09 统一更新版

## 归档课程
1. 课程管理列表找到课程，点击"归档"，阅读影响提示并确认。
2. 归档后：你和原在课学生仍可按原权限查看内容、下载文件；不能新提交、重交、提问、回复、审批、发布或修改课程内容，新学生不能加入。
3. 归档时自动处理：待审批的延期申请标记为已取消（记录"课程归档"）；未发布的定时通知转回草稿并清除排期——恢复课程后不会突然发布旧排期。
4. 阅读和下载统计仍会更新；问答可收紧为私人或撤下公开内容（隐私保护例外）。
5. 已归档课程不能直接删除；如需删除，先"恢复"再使用原有删除确认流程。

## 恢复课程
在课程列表切换到"已归档"，点击"恢复"。恢复后一切按原状态继续：延期申请不会自动恢复，定时通知需要重新排期。

## 复制课程（新学期开课）
1. 点击课程的"复制"。
2. 填写新课程名称和课程代码，选择是否复制资料和作业模板。
3. 复制结果：
   - 新课程为进行中状态，生成新课程 ID 和新邀请码。
   - 作业复制为**草稿**并清空截止时间，保留要求、类型、满分、提交模式等模板设置；分组作业草稿需在新课重新配置分组后才能发布。
   - 资料附件复制到新课程的独立文件路径，删除或修改旧课程不影响新课。
   - **不复制**：学生名单、分组及成员、学生作业、成绩、阅读/下载记录、延期申请、问答和通知。
4. 复制大课程附件时显示处理中，请等待完成提示；失败时自动清理，不会留下半成品课程。

## 常见失败原因
- "课程已归档，请先恢复课程"：修改操作被只读保护拦截。
- "原课程有缺失的资料，请修复后再复制"：先检查缺失附件或取消复制资料。
- 复制请求重复提交会被自动识别，返回同一个结果。
