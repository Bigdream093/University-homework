# 学生：课程提问与公开问答
版本：2026.09 统一更新版

## 用途
在课程内向老师提问，并查看教师整理的全班公开问答。

## 隐私规则（先读这一段）
- 原问题、追问和师生回复只有你和任课教师可见，同组同学也看不到。
- 教师可以另写匿名的"公开摘要 + 公开答复"发布到全班公开问答区，不会直接公开你的原文或身份。
- 学生不能控制、撤回教师整理的公开摘要；如摘要存在不当信息，请联系任课教师处理。
- 归档课程中可以查看历史问答，但不能新提问或回复。

## 操作步骤
1. 进入课程 → "问答"标签，可切换"公开问答"和"我的问答"。
2. 点击"提问"，填写标题和正文后提交。
3. 老师回复后你在"我的提问"中查看；可以继续追问，追问同样仅你和教师可见。
4. 尚未收到回复且从未公开的问题可以编辑或删除；已回复或曾公开的问题请用追问补充。

## 常见失败原因
- 不能编辑/删除：问题已有回复或公开历史，请改用追问。
- 看不到某条公开问答：它可能已被老师撤回或隐藏。
- 退课后不能访问课程问答，历史私人内容继续受保护。
