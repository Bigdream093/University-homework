# 学生：私人问答与公开问答
版本：2026.09 统一更新版

## 用途
在课程内向老师提问，并由你决定问题能否被公开给全班。

## 隐私规则（先读这一段）
- 新问题默认**必须私人**：只有你和任课教师能看原问题及双方回复，同组同学也看不到。
- 提问时可以选择"允许老师向全班公开"。这只是一个**许可**，不代表已经公开——是否公开、何时公开、公开什么内容由老师确认后操作。
- 老师公开的是老师整理的"公开摘要 + 公开答复"，你的原帖和私人追问不会因此公开。
- 学生要求必须私人时，老师无法把问题、追问、回复或摘要向全班公开，界面和后台都会拒绝。
- 你可以随时把问题改回"必须私人"，系统立即撤下已有的公开摘要；已经被同学看到或截图的内容无法追回。
- 归档课程中仍可收紧隐私（改为必须私人），但不能新提问、新回复或新公开。

## 操作步骤
1. 进入课程 → "问答"标签，可切换"公开问答"和"我的问答"。
2. 点击"提问"，填写标题和正文，选择"必须私人（默认）"或"允许老师向全班公开"，确认后提交。
3. 老师回复后你在"我的问答"中查看；可以继续追问，追问默认私人。
4. 尚未收到回复且从未公开的问题可以编辑或删除；已回复或曾公开的问题请用追问补充。

## 常见失败原因
- 不能编辑/删除：问题已有回复或公开历史，请改用追问。
- 看不到某条公开问答：它可能已被老师撤回或隐藏。
- 退课后不能访问课程问答，历史私人内容继续受保护。
