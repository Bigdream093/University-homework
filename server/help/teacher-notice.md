# 教师：发布通知与查看已读
版本：2026.09 统一更新版

## 用途
发布即时或定时通知，查看已读人数和已读学生名单，撤回误发内容。

## 发布通知
课程详情 → "通知"标签 → "发布通知"：
- **存草稿**：仅自己可见，可继续编辑或删除。
- **立即发布**：学生通知列表立即可见。
- **定时发布**：选择未来的北京时间；到点后系统自动发布并计入学生未读。定时通知在发布前学生不可见，可修改时间或取消（取消后转回草稿）。

## 已读统计
- 每条通知显示"累计 X 名学生查看"；点击"已读名单"查看学号、姓名和首次查看时间。
- 学生点击打开全文才算已查看；多次打开、多设备只计一次。
- 名单与累计人数口径一致；退课学生的历史阅读记录保留，不与当前班级人数相除计算比例。
- 编辑正文会使通知显示"已更新"，学生重新查看后计入新版本已读；历史已读记录不会被清除。

## 撤回与删除
- **撤回**：已发布通知可撤回，学生端只显示"该通知已被教师撤回"，不再展示正文；历史已读记录保留。撤回后的通知不能修改，也不能重新发布——需要重新通知时请新建。
- **删除**：只有草稿可以删除；定时通知先取消排期，已发布通知用撤回。

## 常见失败原因
- 定时保存失败"定时发布时间必须是有效的未来北京时间"：重新选择未来时间。
- 已发布通知不能改回草稿或重新定时；系统只允许普通编辑或撤回。
- 服务器停机期间到期的定时通知会在恢复后自动补发，实际发布时间可能晚于计划时间。
