# 学生：登录、加入课程与修改密码
版本：2026.09 统一更新版

## 用途
第一次使用系统时登录账号、加入老师的课程，以及修改初始密码。

## 前提条件
- 老师已在系统中为你建立账号（一般是学号），或告知了课程邀请码。
- 初始密码为 123456，首次登录必须修改。

## 加入课程
1. 登录后进入"我的课程"页面。
2. 在"输入邀请码"框中填写老师提供的 6 位邀请码，点击"加入"。
3. 成功后课程卡片立即出现，卡片上的角标显示你尚未读过或已有更新的通知数量。

## 修改密码
1. 点击右上角头像或个人菜单，进入"修改密码"。
2. 输入初始密码和两次新密码，点击"确认"。
3. 成功后下次登录请使用新密码。

## 成功后看到什么
课程卡片显示课程名称、作业数量和通知未读数。被筛选为"已归档"的课程仍可查看，但不能提交、申请延期或发问。

## 常见失败原因
- 提示"邀请码无效"：核对是否有空格或大小写，仍失败请联系老师确认邀请码是否已重置。
- 提示"课程已归档，不能加入"：课程已结课，联系老师确认是否应该加入新课。
- 账号停用提示：联系老师启用账号。
- 忘记密码：联系任课教师重置为初始密码，重置后请立即修改。
