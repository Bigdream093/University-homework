# 学生：查看通知与未读提醒
版本：2026.09 统一更新版

## 用途
查看老师发布的通知，理解课程角标和通知标签上未读数字的含义。

## 重要规则
- 通知列表只显示摘要；点击打开全文并加载成功后，系统才把这条通知登记为你"已查看"。
- 仅打开列表、刷新页面不算已读；同一通知多次打开只计一次。
- 老师修改已发布通知的正文后，你会看到"已更新"标记，再次打开全文才算读过当前版本。
- 老师撤回的通知只显示"该通知已被教师撤回"，不显示正文，也不计入未读。
- 未读数在进入页面、切换标签、回到浏览器窗口时刷新，页面可见时每 60 秒自动刷新一次。

## 操作步骤
1. 进入"我的课程"，课程卡片角标显示未读通知数量；0 时不出红点。
2. 进入课程，点击"通知"标签，未读通知有未读标识。
3. 点击通知打开全文，关闭后角标和列表状态自动更新。
4. 定时通知到点发布后，最迟在下一次刷新时出现在列表并计入未读。

## 常见失败原因
- 角标不减：网络失败时系统不会提前减数，稍后刷新即可。
- 没看到本该有的通知：确认老师是否已发布（草稿和未到时间的定时通知学生不可见）。
- 已归档课程的通知不计入未读提醒，进入该课程仍可查看历史通知。
