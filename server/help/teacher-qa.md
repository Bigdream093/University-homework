# 教师：回复与管理课程问答
版本：2026.09 统一更新版

## 用途
回复学生提问，决定是否公开，管理问答的解决、置顶和隐藏状态。

## 隐私优先级（必须遵守）
- 学生选择"必须私人"时，问题、追问、回复和公开摘要都**不能**向全班公开——界面禁用，后台也会直接拒绝。
- 学生选择"允许公开"只是许可，公开仍需你手动确认。
- 已有私人回复和私人追问不会随公开操作被自动暴露；公开的内容是你另写的"公开摘要 + 公开答复"。
- 公开范围只限当前课程成员，不生成外部链接。
- 收回公开：撤回公开摘要即时生效，但已被学生看到的内容无法追回。

## 日常操作
1. 课程详情 → "问答"标签。列表可搜索，按"待回复 / 已回复 / 已解决"筛选。
2. 点击问题查看完整对话，输入私人回复点击"发送私人回复"。学生追问后问题回到"待回复"。
3. **公开**：确认学生已允许公开后，点击"整理公开摘要"，核对原问题不含私人信息，填写公开摘要和公开答复，点击"向全班公布"。公开帖只显示学生显示名，管理视图可查学号。
4. **撤回**：点击"撤回公开摘要"，所有公开查询立即不可见。
5. **标记解决 / 置顶 / 隐藏**：标记问题状态；置顶让重要公开内容靠前；隐藏不适宜内容后仅你和提问者可见，不出现在其他学生的列表、计数或搜索中。

## 常见失败原因
- 公开被拒"学生要求必须私人"：这是学生的强制设置，不能绕过；学生本人放宽许可后才能公开。
- 学生改回必须私人后公开摘要自动撤下：正常行为。
- 归档课程只能查看问答和收紧隐私，不能新提问、回复或公开。
