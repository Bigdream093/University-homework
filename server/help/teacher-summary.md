# 教师：成绩汇总、权重与总评导出
版本：2026.09 成绩汇总版

## 用途
在课程页"成绩汇总"标签查看全班每次作业的提交图片与评分，直接修改成绩，设置权重和期末作业，自动计算平时成绩、期末成绩、总成绩，并导出五列成绩表。

## 打开汇总
课程 → "成绩汇总"标签。表格每行一名学生，顺序与学生名单（Excel 原序）完全一致；每次作业一列，右侧固定"平时成绩、期末成绩、总成绩"三栏，均为百分制、保留 1 位小数。

## 查看与修改每次作业
- 作业格显示第一张预览图缩略图，右上角角标为图片总数（如"3张"）；没有预览图时显示源文件名或"在线作答"。
- **点击缩略图/文件名**：打开完整的看图评分工作区，可翻看全部图片、放大、修改成绩、填写评语、退回重做。
- **点击分数**：直接在格内输入新成绩并回车，立即保存。修改会覆盖旧分并把状态置为"已评分"（成绩不保留修改历史）；原评语保持不变。
- 未交显示"未交"，分组作业中未安排到组的学生显示"未安排"，已交未评显示"待批改"，已退回显示"已退回"。

## 权重、期末与占比
- **期末作业**：在顶部下拉中选择一次作业作为期末。每门课只能有一个期末作业，草稿作业不能设为期末；期末作业不参与平时权重。
- **平时占比 / 期末占比**：只填平时占比，期末自动补足 100%；保存时服务端校验两者之和必须为 100。
- **权重设置**：弹窗中为每门平时作业填写权重（默认 1，允许 0=该作业不计入），可"恢复等权"。
- **未交/未评计入方式**：
  - 未交、未评均按 0 分计入（默认）；
  - 未评不计入（待批改、已退回不进分母），未交、未安排仍按 0 分计入。
- 计算公式：某次作业折算分 = 得分 ÷ 满分 × 100；平时成绩 = Σ(折算分×权重) ÷ Σ权重；总成绩 = 平时成绩×平时占比 + 期末成绩×期末占比。期末未指定或未评分时，总成绩暂按平时成绩显示。
- 草稿作业默认隐藏、不参与计算；勾选"显示草稿作业"仅用于查看。
- 修改设置后三栏立即按新设置预览，顶部出现提醒；点击"保存设置"后才正式生效。

## 导出成绩表
- 点击"导出成绩表"生成 Excel：**姓名、学号、平时成绩、期末成绩、总成绩**五列，行序与学生名单严格一致。
- 导出按服务端已保存的设置计算；若有未保存的设置修改，会先自动保存再导出。
- 第二个工作表"计算说明"记录导出时间、口径、占比、期末作业、各作业权重与计入方式，便于留档核对。

## 常见失败原因
- 保存设置被拒：平时与期末占比之和不是 100，或期末作业不是本课程已发布的作业。
- 行内改分被拒：成绩超出该作业满分。
- 归档课程：汇总可查看、可导出，但不能改分、不能保存设置。

## 与学生端的关系
学生端不显示任何成绩、评语与汇总数据；本页所有数据仅教师可见。学生重新提交后，该次提交回到"待批改"，原成绩按退回/重交规则处理。
