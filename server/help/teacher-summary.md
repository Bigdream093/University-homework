# 七、成绩汇总

1. 进入课程的“成绩汇总”栏目，按学生查看各次作业及平时成绩、期末成绩和总成绩。
2. 点击“评分”“查看评分”或“查看退回作业”，进入统一批改界面。可查看全部预览图、答案和源文件。
3. 在“期末作业”中指定一次作业作为期末。草稿作业不能设为期末作业。
4. 设置“平时占比”后，期末占比会自动补足至 100%。
5. 点击“占比设置”，填写各次平时作业占总成绩的百分比。各项合计必须等于平时占比；例如平时占比为 30%，三次作业可各占 10%。
6. 可选择未交、未批改作业的计入方式。调整后请核对页面预览，并点击“保存设置”。
7. 点击“导出成绩表”，导出姓名、学号、平时成绩、期末成绩和总成绩。
8. 课程归档后仍可查看和导出成绩，但不能继续修改评分和成绩设置。

成绩及教师内部评语仅教师端可见。
