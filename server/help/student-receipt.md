# 学生：提交历史与提交回执
版本：2026.09 统一更新版

## 用途
在提交之后随时核对"当时交了什么、什么时候交的、是否准时"，并获得可保存的凭据。

## 回执包含什么
课程、作业、你的学号姓名、回执编号、服务器提交时间、实际文件名与大小（或在线作答标识）、本次提交序号、当次适用的截止时间、准时/迟交状态。获准延期的提交显示"按批准的个人截止时间判定"。

## 操作步骤
1. 打开作业详情，点击"历史与回执"（或"提交历史"）。
2. 每条历史显示提交时间、次数、迟交状态和文件状态；仍保留的文件可点击"下载此版本"。
3. 点击"下载回执"保存文本回执，可长期留存。

## 重要规则
- 回执保存提交当时的快照，不因老师后来改课程名、改截止或审批延期而改写。
- 覆盖模式下旧文件被替换后，旧回执仍然保留，但会标记"原文件已被替换"，不能保证还能重新下载该文件。
- 历史数据中缺失的信息显示"未记录"，系统不会倒填。
- 回执只给你本人和任课教师查看；其中不含成绩和教师私密评语。
- 分组作业整组共用一份回执，显示小组名称、成员快照和实际提交人。

## 常见失败原因
- "回执不存在"：核对回执编号是否属于本作业。
- "原文件已替换或不可用"：覆盖提交后旧实体文件已删除，以回执记录为准。
